
Opción A: Crear primero en GitHub, después clonar
bash
# 1. Creás el repo en github.com (con botón "New repository")
# 2. Lo clonás a tu compu
git clone https://github.com/usuario/nombre-repo.git
cd nombre-repo


Opción B: Crear la carpeta local primero, después conectarla
bash
cd mi-carpeta
git init
git add .
git commit -m "primer commit"

# ahora la conectás a un repo vacío que creaste en GitHub
git remote add origin https://github.com/usuario/nombre-repo.git
git branch -M main --> renombra la rama principal de master -> main
git push -u origin main


git branch => para saber en que rama estoy parado 


Paso 2: Crear las tres ramas nuevas desde main
bash

git checkout main
git branch desarrollo --> creamos la rama de desarrollo
git branch testing --> creamos la rama de testing
git branch produccion --> creamos la rama de produccion

git branch --> vemos todas las ramas


----------------------------------------------------------------------
* EN LA RAMA PRINCIPAL DE DESARROLLO *

git checkout desarrollo => nos paramos en la rama de desarrollo
git add . => sumamos todos los cambios pendientes a la rama de desarrollo
git commit -m "cambios del dia de la fecha"
git push -u origin desarrollo => subimos todos los cambios de la rama de desarrollo a la nube

------------------------------------------------------------------------
* EN LA RAMA DE TESTING DESARROLLO => TESTING *

git checkout testing => nos paramos en la rama de testing
git merge desarrollo => le decimos a git que actualice testing con los commits nuevos que tiene Desarrollo que no tiene para que quede nivelado
git push -u origin testing => le decimos que actualice en la nube la rama de testing


------------------------------------------------------------------------
* EN LA RAMA DE TESTING DESARROLLO => PRODUCCION *

git checkout produccion => nos paramos en la rama de produccion
git merge desarrollo => le decimos a git que actualice testing con los commits nuevos que tiene Desarrollo que no tiene para que quede nivelado
git push -u origin testing => le decimos que actualice en la nube la rama de testing
